# Проект "HOMEWORK"

## Описание:

Проект "Homework" - это домашнее задание в рамках курса "Python-разработчик". 
В нём создаём виджет для обслуживания банковских операций клиента.
В данный момент содержит функции, которые маскируют номер карты и номер счёта клиента,
фильтруют список банковских операций, сортируют его по убыванию, либо по возрастанию их даты, 
плюс вспомогательные функции для реализации описанных возможностей.

## Установка:

1. Клонируйте репозиторий:
```
git clonegit@github.com:Vadimko4/Homework.git
```
или
```
git clone https://github.com/Vadimko4/Homework.git
```

2. Установите зависимости:
```
poetry install
```

## Использование:

Запустите на выполнение файл main.py
