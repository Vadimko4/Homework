# Проект "HOMEWORK"

## Описание:

Проект "Homework" - это домашнее задание в рамках курса "Python-разработчик". 
В нём создаём виджет для обслуживания банковских операций клиента.
В данный момент содержит функции, которые маскируют номер карты и номер счёта клиента,
фильтруют список банковских операций, сортируют его по убыванию, либо по возрастанию их даты, 
плюс вспомогательные функции для реализации описанных возможностей.

Проект обновлён. Добавлены тесты всех функций, всех модулей. Тестируются как штатные ситуации, 
так некорректные случаи: пустые строки на входе, данные неправильной длины, неправильного формата -
вместо цифр, буквы, конфликтные случаи, когда дата операций, например, совпадает.

В обновлении от 12.02.25 добавлен модуль generators. В нём реализованы следующие функции:
1. filter_by_currency - фильтрует список транзакций по указанной валюте
2. transaction_descriptions - вытаскивает из списка транзакций описание каждой
3. card_number_generator - генерирует список номеров карт в указанном диапазоне в виде по 4 цифры, разбитые пробелами
4. get_valid_card_number_form - вспомогательная к card_number_generator, она как раз и делает номер карты нужного формата с пробелами

В обновлении от 16.02.25 добавлен модуль decorators. В нём реализован декоратор log(), который логирует работу функции.
Если аргумент не указать, логирует в консоль, иначе в файл, с указанным в качестве параметра функции именем.

Все функции проекта оттестированы в различных условиях: в штатных и в нештатных, когда в параметрах всякая неожидаемая ерунда,
либо когда генераторы ничего не возвращают, за отсутствием подходящей под условия запроса информации. Дабы программа не падала с ошибками.
